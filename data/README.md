# Data files

`hotels_clean_no_zero_guests.csv` is the analysis dataset committed for group review. It contains 72,973 rows and 24 variables after removal of the 31 records with `adults + children + babies == 0`.

The Part C Rmd reads this file only while the modelling section is developed separately. For the group submission, use Part A's final data code and delete the temporary import section marked in the Rmd.

Source: Antonio, N., de Almeida, A., & Nunes, L. (2019). *Hotel booking demand datasets*. *Data in Brief, 22*, 41–49. https://doi.org/10.1016/j.dib.2018.11.126
