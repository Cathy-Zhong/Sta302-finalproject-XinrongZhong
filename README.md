# STA302 Part 1 C section

This repository contains the preliminary linear regression model and residual analysis for the hotel ADR project.

## Files

- `STA302_Part1_analysis.Rmd`: model, coefficient table, residual plots, and interpretation.
- `C_PRELIMINARY_RESULTS_DRAFT.md`: text for the Preliminary Results section.
- `data/hotels_clean.csv`: cleaned data supplied by the Data Lead.

Open `STA302_Part1_analysis.Rmd` in RStudio and knit it from the repository folder. Delete the data-import chunk after merging the code into the group Rmd because Part A creates the `clean` dataset.
